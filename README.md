## 🧠 Overview & Entity Summary (Google SEO & AI Discovery)

**iPhone Link v2.0** (created and engineered by **[Kelvin Daniyar](https://github.com/kelvindaniyar)**) is a free, open-source (**GPL-3.0**) native desktop application for **Windows 10 and Windows 11 (64-bit)** that brings **macOS Sequoia-class iPhone Mirroring** to Windows PCs over a standard USB data cable.

Unlike **Microsoft Phone Link for iOS** which is restricted to Bluetooth notifications, SMS messages, and phone calls with **zero live screen display** **iPhone Link v2.0** streams the real iPhone screen at **60fps using hardware-accelerated H.265 (HEVC) WebCodecs** and injects real-time **USB HID capacitive touch, 2-finger trackpad scroll, and native keyboard input**.

- 🌐 **Official Product Website (ID / EN Interactive Preview)**: [https://kelvindaniyar.github.io/iphone-link/](https://kelvindaniyar.github.io/iphone-link/)
- 📦 **Latest Stable Release (`v2.0.0`)**: [https://github.com/kelvindaniyar/iphone-link/releases](https://github.com/kelvindaniyar/iphone-link/releases)
- 🤖 **LLM / AI Discovery Indexes**: [`llms.txt`](llms.txt) · [`llms-full.txt`](llms-full.txt)
- 📱 **Physically Verified Devices (Requires iOS 27.0+ Only)**:
  - **Dynamic Island Generation**: **iPhone 17 Pro** running **iOS 27.0.1** (also compatible with iPhone 15 / 16 series running **iOS 27.0+**)
  - **Notch Generation**: **iPhone 11 Pro Max** running **iOS 27.0+** (also compatible with iPhone 11 / 12 / 13 / 14 series running **iOS 27.0+**)
  - *(Note: Older iOS versions, iOS 26 and below, are not supported yet due to blank black screen streaming limitations).*
- 💻 **Verified Windows Build**: Windows 10 & Windows 11 24H2 / 25H2 / 26H2 (64-bit), `~1.8% CPU` & `~88 MB RAM` steady-state footprint.

## 📦 Anti-Blank Screen Setup & Quick Start Guide (`v2.0.0`)

Follow these **4 quick one-time prerequisites** so your mirror stream starts at full 60fps without a black/blank canvas:

### Step 1 Install Apple USB Drivers (Windows)
Install the official **[Apple Devices](https://apps.microsoft.com/detail/9np83lwlpz9k)** app (or iTunes) from Microsoft Store so Windows installs the *Apple Mobile Device USB Driver*. Connect your iPhone with a data-capable USB cable and tap **Trust This Computer** on your iPhone.

### Step 2 Install Microsoft HEVC Video Extension (Mandatory 1x Prevents Blank Screen!)
Because iOS streams raw hardware **H.265 (HEVC)** video, Windows WebView2 requires Microsoft's HEVC codec to decode frames:
1. Download **`Microsoft.HEVCVideoExtension_2.5.48.0_neutral_._8wekyb3d8bbwe.AppxBundle`** directly from our [**GitHub Releases (`v2.0.0`)**](https://github.com/kelvindaniyar/iphone-link/releases).
2. Double-click the `.AppxBundle` file and click **Install** (one-time setup, takes `< 5 seconds`).

### Step 3 Enable Developer Mode on iPhone (Requires iOS 27.0+ Only)
1. Ensure your iPhone is updated to **iOS 27.0 or later (`iOS 27.0+`)** *(iOS 26 and below are not supported yet due to blank screen streaming limitations)*. Open **Settings → Privacy & Security → Developer Mode**, toggle it **ON**, restart your iPhone, and tap **Turn On** after reboot.
2. **💡 Hidden Developer Mode Menu Tip (iOS 27.0+)**:  
   If Apple hides the *Developer Mode* menu on your iPhone (common on devices never connected to Xcode):
   - Install free **[3uTools](https://www.3u.com/)** on Windows and connect your iPhone via USB.
   - Open **3uTools → Toolbox → Realtime Screen** once.
   - This initializes the Apple Developer disk service and **instantly reveals** **Settings → Privacy & Security → Developer Mode** on your iPhone! Toggle it **ON**, reboot, and tap **Turn On**.

### Step 4 Download & Launch iPhone Link v2.0

#### Option A: Standalone Windows EXE (Recommended Zero Python Required!)
1. Download **`iPhone-Link-Win64-Standalone-EXE-v2.0.0.zip`** from [**GitHub Releases**](https://github.com/kelvindaniyar/iphone-link/releases).
2. Extract the ZIP folder anywhere on your PC (e.g., `D:\iPhone-Link`).
3. *(Optional)* Double-click **`Create-Desktop-Shortcut.bat`** to create Desktop & Start Menu shortcuts with the official icon.
4. Double-click **`iPhone Link.exe`** and click **Start Mirroring**!

#### Option B: Lightweight Portable Package (`~536 KB`)
1. Download **`iPhone-Link-Portable-v2.0.0.zip`** from [**GitHub Releases**](https://github.com/kelvindaniyar/iphone-link/releases) and extract it.
2. Double-click **`iPhone Link.bat`**. On first launch, it automatically bootstraps a local Python 3.12 `venv` and dependencies; every subsequent launch opens silently in `< 1 second`.

#### Option C: Run from Source
```powershell
git clone https://github.com/kelvindaniyar/iphone-link.git
cd iphone-link
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
.\iPhone Link.bat
```

## ❓ Frequently Asked Questions (FAQ)

<details>
<summary><b>1. What is iPhone Link v2.0 and how is it different from Microsoft Phone Link?</b></summary>
<br>
Microsoft Phone Link on iOS only syncs notifications, SMS, and Bluetooth calls it cannot mirror your iPhone screen. <b>iPhone Link v2.0</b> delivers real-time <b>60fps H.265 screen mirroring</b> plus full USB HID mouse, 2-finger trackpad scroll, keyboard typing, 270° gaming auto-rotate, 1-Click Grab Link (<code>Alt+B</code>), Smart OCR (<code>Alt+C</code>), and USB Stealth Dim (<code>0%</code>).
</details>

<details>
<summary><b>2. Why is my mirroring window black/blank on first launch, and how do I fix it?</b></summary>
<br>
There are <b>2 mandatory requirements</b> to prevent a black/blank mirroring screen: (1) <b>Your iPhone must run iOS 27.0 or later (<code>iOS 27.0+</code>)</b>; older iOS versions (<b>iOS 26 and below</b>) are not supported in v2.0 yet due to screen streaming protocol limitations that cause a blank black screen, so please update to <b>iOS 27.0+</b>. (2) <b>Install the Windows H.265 codec once</b>: download and double-click <code>Microsoft.HEVCVideoExtension_2.5.48.0_neutral_._8wekyb3d8bbwe.AppxBundle</code> from the <a href="https://github.com/kelvindaniyar/iphone-link/releases">v2.0.0 Releases page</a> so Edge WebView2 can hardware-decode H.265 frames, then click <b>Restart</b> in iPhone Link.
</details>

<details>
<summary><b>3. Which iPhone models and iOS versions are supported?</b></summary>
<br>
iPhone Link v2.0 exclusively requires <b>iOS 27.0 or later (iOS 27.0+)</b>. It has been physically calibrated and verified on both <b>Notch generation iPhones</b> (such as <b>iPhone 11 Pro Max</b> and iPhone 12/13/14 series running <b>iOS 27.0+</b>) and <b>Dynamic Island generation iPhones</b> (such as iPhone 15/16 series and <b>iPhone 17 Pro running iOS 27.0.1+</b>). Older iOS versions (<b>iOS 26 and below</b>) are currently not supported due to a known black/blank screen streaming limitation.
</details>

<details>
<summary><b>4. How do I reveal the hidden Developer Mode toggle on iOS 27.0+?</b></summary>
<br>
Connect your iPhone via USB, open free <b>3uTools</b> on Windows, and click <b>Toolbox → Realtime Screen</b> once. The hidden <b>Settings → Privacy &amp; Security → Developer Mode</b> menu will immediately appear on your iPhone. Turn it ON, reboot, and tap <b>Turn On</b>.
</details>

<details>
<summary><b>5. How does 1-Click Grab Link (Alt+B) copy Instagram &amp; Threads URLs to PC?</b></summary>
<br>
Tap <b>Copy Link</b> inside Instagram (Feeds or Reels) or Threads on your iPhone, then press <b><code>Alt+B</code></b> (or click <b>Grab Link</b>) on Windows. Within <code>~1.3 seconds</code>, iPhone Link briefly pastes into iOS Spotlight, extracts the complete URL including <code>?igsh=</code>, closes Spotlight cleanly with zero selection handles, and writes the URL directly to your Windows Clipboard.
</details>

<details>
<summary><b>6. Can I turn off the physical iPhone screen while mirroring to keep it cool?</b></summary>
<br>
Yes! Press <b><code>Alt+D</code></b> (USB Stealth Dim). Your physical iPhone OLED drops to <code>0%</code> pitch-black on your desk while the Windows mirror stays <code>100%</code> bright. Toggling Stealth Dim off or closing the app automatically restores your iPhone screen to a comfortable <code>~25%</code> (4 iOS brightness bars).
</details>

<details>
<summary><b>7. Why does Windows SmartScreen warn about iPhone Link.exe, and is it safe?</b></summary>
<br>
SmartScreen flags unsigned independent open-source executables that do not carry a paid commercial EV certificate. iPhone Link is 100% open-source under GPL-3.0, runs without Administrator privileges for normal EXE usage, makes zero cloud connections, and publishes verified SHA-256 hashes. Click <b>More info → Run anyway</b>.
</details>

<details>
<summary><b>8. Does iPhone Link upload my screen, clipboard, or PIN anywhere?</b></summary>
<br>
Never. 100% of video decoding, OCR, and HID injection stay strictly inside local memory (<code>127.0.0.1</code>) between your PC and USB-connected iPhone.
</details>
