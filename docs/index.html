DUAL KONEKTIVITAS

Kabel atau Wi-Fi, kamu yang pilih.

Kebebasan penuh memilih latensi nol via USB untuk game kompetitif atau mirroring Wi-Fi rapi tanpa kabel di meja kerja.

Mode Kabel USB & Wi-Fi Low-Latency

v4.0 menghadirkan switch mode koneksi langsung di jendela aplikasi maupun panel Settings tanpa konfigurasi rumit.

  • Kabel USB 60fps H.265 Zero-Copy dengan TCP_NODELAY dan buffer 240 paket anti-patah.
  • Mode Wi-Fi Low-Latency melalui mDNS _remotepairing._tcp.local untuk perangkat terpercaya di subnet lokal.
  • Audio Tanpa Kabel ke speaker/headset PC via WASAPI & Bluetooth A2DP lengkap dengan preset buffer.

Lingkungan Teruji Fisik iOS 27.2

Tervalidasi di perangkat fisik iPhone 17 Pro, iPhone 11 Pro Max, dan profil iPad (4:3) di Windows 10 & Windows 11 64-Bit.

  • 1 Pasang Apple Devices / iTunes dari Microsoft Store agar driver Apple Mobile Device USB aktif.
  • 2 Aktifkan Developer Mode: Settings -> Privacy & Security -> Developer Mode (wajib iOS 27.0+).
  • 3 Tips Jika Tersembunyi: Buka 3uTools -> Toolbox -> Realtime Screen 1x lewat USB agar toggle Developer Mode langsung muncul.

CATATAN PERSONAL

Sebuah catatan yang jujur dari Kelvin Daniyar

Dari umpan balik lebih dari 2.223+ pengguna aktif pada rilisan v2.0, saya mendapati dua tantangan nyata: kendala crash Python.Runtime.dll akibat Zone.Identifier Windows dan kebingungan menyiapkan Python maupun codec HEVC manual. Karena itulah iPhone Link v4.0.0 dibangun ulang sepenuhnya di atas Native Rust agar langsung jalan seketika di setiap PC Windows.

Melalui lebih dari 186 tahapan rekayasa serta pengujian fisik di iPhone 17 Pro, iPhone 11 Pro Max (iOS 27.2), dan profil iPad (4:3), tujuan saya tetap sama: menghadirkan jembatan kristal paling cepat antara perangkat Apple dan PC Windows secara gratis untuk selamanya.
