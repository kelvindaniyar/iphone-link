JEMBATAN DIGITAL • ICLOUD SHORTCUT

Instant 100% Accurate Link Transfer via iOS 27 Shortcut (< 5 ms)

Kirim link Instagram, Threads, YouTube, TikTok, atau Shopee langsung dari menu Bagikan (Share Sheet) iPhone ke clipboard Windows dalam < 5 ms. Aman — hanya menerima kiriman tautan di Wi-Fi rumah Anda.

Penting: Gunakan IP Wi-Fi PC Anda, Bukan IP iPhone!

Panel Status Wi-Fi iPhone Link menampilkan IP iPhone (misal 192.168.100.41) untuk koneksi layar. Untuk Apple Shortcuts, selalu gunakan IP PC pada kotak iOS 27 Shortcut — URL Server PC di aplikasi (misal http://192.168.100.8:8765/c?u=), bukan IP iPhone!

RECOMMENDED • 1-CLICK OFFICIAL iCLOUD SHORTCUT Dual-Mode (Share Sheet + Double Back Tap < 5 ms)

Unduh 1-Klik Official iCloud Shortcut (Tanpa Perlu Klik Copy Link!)

Pasang pintasan resmi Send to iPhone Link langsung ke Apple Shortcuts di iPhone dalam 1 ketukan, lalu sesuaikan 1 angka IP PC saja:

Pasang Official iCloud Shortcut (iPhone)
  1. Ketuk Add Shortcut (Tambahkan Pintasan) setelah membuka link resmi iCloud di iPhone Anda.
  2. Buka edit pintasan Send to iPhone Link, gulir ke blok paling bawah (Get contents of URL), lalu ganti IP contoh 192.168.100.8 dengan IP Wi-Fi PC Anda dari aplikasi (jangan gunakan IP iPhone!).
Alur Pintasan Ganda (6 Blok): If [Shortcut Input] [has any value] → Get URLs from [Shortcut Input] / Otherwise → Get Clipboard → Get URLs from [Clipboard] → End If → URL Encode [If Result] → Get Contents of URL [http://<IP-PC>:8765/c?u=[URL Encoded Text]]
OPTION A • SIRI / AI

1 Klik Prompt Siri / Apple Intelligence

Salin prompt berikut atau klik Copy Prompt Shortcut di dalam aplikasi, lalu minta Siri membuatkan Shortcut-nya otomatis:

Create a new Shortcut named "Send to iPhone Link" that appears in the Share Sheet (with If there's no input: Get Clipboard). First action: Get URLs from Shortcut Input. Second action: URL Encode the URLs. Third action: Get Contents of URL "http://<PC-LAN-IP>:8765/c?u=" followed by the URL Encoded Text.
OPTION B • 3 BLOCKS

Setup Manual 3 Blok Apple Shortcuts (~20 Detik)

  1. Buka Shortcuts di iPhone → Ketuk + → Beri nama Send to PC.
  2. Aktifkan Show in Share Sheet: Receive [Any] input from [Share Sheet].
  3. Tambah aksi URL: http://<IP-PC-ANDA>:8765/c?u=[Shortcut Input].
  4. Tambah aksi Get Contents of URL (Method: GET). Tinggal Share → Send to PC → Ctrl+V!
1-TAP • BACK TAP & SHARE SHEET

Tips Penggunaan Cepat (1-Tap Share Sheet & Double Back Tap)

  • Cara A (Double Back Tap): Salin link lalu ketuk punggung iPhone 2× → langsung masuk clipboard PC (< 5 ms)!

CATATAN PERSONAL

Sebuah catatan yang jujur dari Kelvin Daniyar

Dari umpan balik lebih dari 2.223+ pengguna aktif pada rilisan v2.0, saya mendapati dua tantangan nyata: kendala startup akibat blokir file unduhan Windows pada komponen lama, dan kerumitan memasang Python serta codec HEVC secara manual. Karena itulah iPhone Link v4.0.0 dibangun ulang sepenuhnya di atas Native Rust agar langsung jalan seketika di setiap PC Windows.

Melalui 217 tahapan rekayasa serta pengujian fisik di iPhone 17 Pro, iPhone 11 Pro Max (iOS 27.2), dan profil iPad (4:3), tujuan saya tetap sama: menghadirkan jembatan kristal paling cepat antara perangkat Apple dan PC Windows secara gratis untuk selamanya.

FAQ v4.0.0

Pertanyaan yang sering diajukan.

iPhone Link v4.0.0 bermigrasi ke mesin Native Rust (1.51 MB, waktu buka < 0.25 dtk, ~95 MB total RAM dengan pembersihan memori otomatis), salin teks instan 38.8 ms, transfer link 1-Tap iOS 27 Shortcut (< 5 ms), bebas error aplikasi lama, mendukung Wi-Fi Low Latency, dukungan iPad 4:3, Bahasa ID/EN terpadu, System Tray Start with Windows, Auto-Update OTA, serta Installer Setup.exe 64-bit All-in-One lengkap dengan Driver USB Apple offline & HEVC.
Tidak sama sekali. iPhone-Link-v4.0.0-Setup.exe sudah membawa runtime terisolasi, Driver USB Apple resmi (AppleMobileDeviceSupport64.msi) offline, aturan Firewall LAN, dan ekstensi HEVC langsung di C:\Program Files\iPhone Link.
Teruji fisik pada iPhone 17 Pro (Dynamic Island) dan iPhone 11 Pro Max (Notch) dengan iOS 27.2 serta profil iPadOS 4:3. Memerlukan iOS 27.0+ dengan Developer Mode aktif. Jika menu Developer Mode masih tersembunyi di iPhone, cukup klik tombol Munculkan Menu Developer Mode (1-Klik) di kartu Detail Perangkat & Koneksi — tanpa perlu download 3uTools!
Stealth Dim (Alt+D) menurunkan kecerahan OLED fisik ke 0% agar perangkat tetap dingin & privat lalu otomatis memulihkan kecerahan saat ditutup. PIN opsional tersimpan lokal di PC Anda saja tanpa pernah diunggah.
Ya. Mulai Tahap 176 hingga v4.0.0, aplikasi mengunci tampilan kaca akrilik Windows 11 sehingga efek buram elegan pada Mode Gelap maupun Mode Terang tetap jernih meski Anda membuka jendela lain.
Pengguna Installer Setup.exe dapat menghapus lewat Installed Apps (Apps & Features) Windows yang otomatis menghentikan proses, membersihkan firewall, shortcut, & cache aplikasi. Pengguna Portable dapat menjalankan Uninstall-iPhone-Link.bat.
