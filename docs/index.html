TIGA CARA TERHUBUNG

Kabel USB, Wi-Fi, atau AirPlay. Pilih yang paling pas.

Mau respons tercepat lewat kabel, bebas bergerak di Wi-Fi, atau langsung terhubung dengan AirPlay? Semua ada di satu aplikasi ringan.

USB 60 FPS, Wi-Fi, & AirPlay HD

iPhone Link 5.0.2 menyesuaikan jalur koneksi secara jujur di satu jendela Native Rust: USB & Wi-Fi kontrol penuh tanpa aplikasi tambahan untuk iOS 27+, serta AirPlay tampilan & suara untuk iOS 17-26.

  • iOS 27+ (USB & Wi-Fi 60 FPS + Kontrol Penuh): pasang kabel sekali untuk atur Wi-Fi tanpa aplikasi tambahan, penuh ujung ke ujung di semua iPhone, plus mouse, keyboard, trackpad 30%-200%, & buka kunci PIN.
  • iOS 17-26 (AirPlay HD - Tampilan & Audio Saja): kartu pilihan jujur tanpa pengalihan diam-diam serta tombol 1-klik pindah ke AirPlay.
  • Suara iPhone otomatis menyala di PC beserta koneksi Bluetooth aktif, serta sinkron dengan tombol mute di bilah atas.

Siap di iOS 17-27 & Windows 10/11

Teruji langsung pada iPhone 17 Pro, iPhone 11 Pro Max, dan iPad 4:3 di Windows 10 serta Windows 11 64-Bit.

  • 1 Jalankan Installer iPhone-Link-v5.0.2-Setup.exe (51.67 MB): driver Apple dan codec video per-machine terpasang otomatis tanpa perlu ribet.
  • 2 Untuk kontrol penuh USB atau Wi-Fi di iOS 27+, aktifkan Developer Mode via tombol 1-klik; tersedia tombol Salin Log Diagnostik Zero-PII jika butuh bantuan.
  • 3 Untuk iPhone atau iPad dengan iOS 17-26, pilih Screen Mirroring di Control Center lalu ketuk iPhone Link untuk AirPlay tampilan layar & suara ke PC.

JEMBATAN DIGITAL • ICLOUD SHORTCUT

Transfer Link 100% Akurat via iOS Shortcut (< 5 ms)

Kirim link Instagram, Threads, YouTube, TikTok, atau Shopee langsung dari menu Bagikan (Share Sheet) iPhone ke clipboard Windows dalam < 5 ms. Aman, hanya menerima kiriman tautan di Wi-Fi lokal Anda.

Penting: Gunakan IP Wi-Fi PC Anda, Bukan IP iPhone!

Panel Status Wi-Fi iPhone Link menampilkan IP iPhone (misal 192.168.1.25) untuk koneksi layar. Untuk Apple Shortcuts, selalu gunakan IP PC pada kotak iOS Shortcut (URL Server PC) di aplikasi (misal http://192.168.1.10:8765/c?u=), bukan IP iPhone.

RECOMMENDED • 1-CLICK OFFICIAL iCLOUD SHORTCUT Dual-Mode (Share Sheet + Double Back Tap < 5 ms)

Unduh 1-Klik Official iCloud Shortcut (Tanpa Perlu Klik Copy Link!)

Pasang pintasan resmi Send to iPhone Link langsung ke Apple Shortcuts di iPhone dalam 1 ketukan, lalu sesuaikan 1 angka IP PC saja:

Pasang Official iCloud Shortcut (iPhone)
  1. Ketuk Add Shortcut (Tambahkan Pintasan) setelah membuka link resmi iCloud di Safari iPhone Anda.
  2. Buka edit pintasan Send to iPhone Link, gulir ke blok paling bawah (Get contents of URL), lalu ganti IP contoh 192.168.1.10 dengan IP Wi-Fi PC Anda yang tampil di kotak URL Server PC di aplikasi (jangan gunakan IP iPhone).
Alur Pintasan Ganda (6 Blok): If [Shortcut Input] [has any value] → Get URLs from [Shortcut Input] / Otherwise → Get Clipboard → Get URLs from [Clipboard] → End If → URL Encode [If Result] → Get Contents of URL [http://<IP-PC>:8765/c?u=[URL Encoded Text]]
OPTION A • SIRI / AI

1 Klik Prompt Siri / Apple Intelligence

Salin prompt berikut atau klik Copy Prompt Shortcut di dalam aplikasi, lalu minta Siri membuatkan Shortcut-nya otomatis:

Create a new Shortcut named "Send to iPhone Link" that appears in the Share Sheet (with If there's no input: Get Clipboard). First action: Get URLs from Shortcut Input. Second action: URL Encode the URLs. Third action: Get Contents of URL "http://<PC-LAN-IP>:8765/c?u=" followed by the URL Encoded Text.
OPTION B • 3 BLOCKS

Setup Manual 3 Blok Apple Shortcuts (~20 Detik)

  1. Buka Shortcuts di iPhone, ketuk +, lalu beri nama Send to PC.
  2. Aktifkan Show in Share Sheet: blok atas Receive Any input from Share Sheet.
  3. Tambah aksi URL: http://<IP-PC-ANDA>:8765/c?u=[Shortcut Input] (salin IP PC dari aplikasi).
  4. Tambah aksi Get Contents of URL (Method: GET). Selesai, tinggal Share ke Send to PC lalu Ctrl+V di PC.
1-TAP • BACK TAP & SHARE SHEET

Tips Penggunaan Cepat (1-Tap Share Sheet & Double Back Tap)

  • Cara A (Double Back Tap < 5 ms): Salin link di Instagram/TikTok/Threads/YouTube, lalu ketuk punggung iPhone 2x (Settings, Accessibility, Touch, Back Tap, Send to PC) agar langsung masuk clipboard PC.
  • Cara B (1-Tap Share Sheet Tanpa Copy Link): Pada blok Receive Any input from Share Sheet, pilih If there's no input: Get Clipboard, lalu sambungkan Shortcut Input ke URL Encode dan Get Contents of URL.

FAQ v5.0.2

Pertanyaan yang sering diajukan.

iPhone Link 5.0.2 memakai mesin Native Rust tanpa mesin browser berat di belakang layar (~45 MB RAM saat diam, ~79 MB saat mirroring), terbuka seketika, dengan pemasangan USB iPhone 11 sampai 14 di iOS 27 yang langsung tampil, Wi-Fi 60fps tanpa aplikasi tambahan, layar penuh ujung ke ujung dari iPhone 11 Pro Max hingga 17 Pro, serta menjaga kode perangkat tetap tersembunyi dari layar.
Jika sudah memakai versi 5.0.0 atau 5.0.1, cukup tekan tombol Periksa Pembaruan di dalam aplikasi. Untuk pengguna versi 4.0, tutup versi 4.0 terlebih dahulu lalu unduh dan pasang versi 5.0.2 satu kali secara manual (Setup.exe 51.67 MB atau Portable ZIP 9.31 MB); pengaturan dan PIN tersimpan tetap terbaca otomatis.
Tidak perlu. Installer Setup.exe (51.67 MB) sudah menyertakan driver USB Apple dan codec video untuk akun user standar, serta bekerja langsung untuk USB maupun pengaturan Wi-Fi tanpa perlu membuka 3uTools atau memasang Python. Untuk pengguna Portable di Windows 10 yang belum memiliki codec video HEVC, aplikasi menyediakan pilihan untuk memasangnya atau memakai AirPlay.
Dulu file Portable berukuran kecil karena masih menumpang aplikasi tambahan yang harus sudah terpasang di Windows. Sekarang semua mesinnya sudah menyatu mandiri di dalam 1 paket ringkas (10 berkas), jadi kamu tinggal ekstrak dan langsung jalan tanpa perlu menginstal apa pun lagi.
Pada iOS 27+ (teruji di iPhone 17 Pro & iPhone 11 Pro Max), kabel USB dan Wi-Fi mendukung 60 FPS lengkap dengan kontrol penuh mouse, keyboard, trackpad, serta buka kunci PIN. Pada iOS 17-26, mirroring berjalan lewat Mode AirPlay (tampilan layar & audio saja tanpa kontrol PC) karena keterbatasan sistem Apple. Jika menu Developer Mode tersembunyi, colok USB lalu klik tombol bantu 1-klik di aplikasi.
Tekan Alt+D untuk meredupkan layar fisik iPhone ke titik paling gelap supaya baterai hemat, suhu tetap dingin, dan orang di sekitarmu tidak mengintip, sementara layar di PC tetap cerah 100%. Kamu juga dapat menyimpan PIN 6-digit di PC untuk membangunkan dan membuka iPhone lewat Alt+U, serta menghapus semua data privasi kapan saja dalam 1 klik.
Ya. Pada versi 5.0, jendela kaca buram tetap menyala lembut mengikuti warna wallpaper desktop baik di Mode Gelap maupun Mode Terang meski kamu sedang mengklik jendela lain. Saat membuka mode layar penuh dalam posisi tegak, sisi kiri dan kanan juga otomatis dilapisi kaca buram yang rapi.
Jika memasang lewat Setup.exe, cukup hapus lewat menu Installed Apps di Pengaturan Windows agar seluruh berkas aplikasi, pintasan, dan pengaturan lokal langsung bersih. Untuk edisi Portable, cukup jalankan file Uninstall-iPhone-Link.bat lalu hapus foldernya.

Privasimu tetap milikmu.

Tanpa akun. Tanpa cloud. Tanpa pelacakan. Layar, suara, teks yang kamu salin, hingga PIN hanya berjalan langsung antara iPhone dan PC Windows-mu.
